# Project Docs

## Goal
A living documentation set that explains what exists, why it exists, and how to evolve it safely.

## How to use
1. Start with 01_project_overview.md
2. Track progress in 02_scope_and_milestones.md
3. Keep the truth in 03_architecture.md and 04_backend_api_contract.md
4. Keep security rules in 06_security_and_secrets.md
5. After every meaningful change update 12_change_log.md
6. When a decision is not obvious record it in 13_decisions_log.md
7. If you touch files update 08_files_map.md
